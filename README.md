Playlist Maker - это мобильное приложение для Android, позволяющее пользователю слушать музыку онлайн. Интерфейс и функциональность вдохновлены такими сервисами, как Яндекс Музыка и Spotify, но с упором на простоту, скорость работы и персонализацию под предпочтения пользователя.

Приложение поддерживает:
- потоковое воспроизведение аудиотреков;
- создание и управление плейлистами;
- создание библиотеки с избранными треками;
- переключение между светлой и тёмной темами.

## Функциональность 
- 🔍 Поиск музыки по названию, исполнителю или альбому
- 🎧 Аудиоплеер с поддержкой кэширования
- 📂 Создание плейлистов
- ❤️ Возможность добавления в избранное
- 🌓 Поддержка тёмной темы
- 🎛️ Минималистичный UI

##  Технологии
Язык: Kotlin

Архитектура: MVVM

UI: XML

Сетевой слой: Retrofit + OkHttp

База данных: Room

DI: Koin
